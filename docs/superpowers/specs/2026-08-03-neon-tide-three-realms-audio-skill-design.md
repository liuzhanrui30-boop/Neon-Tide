# Neon Tide 2.2 · 三界跃迁、动态音频与主动技能设计规格

## 1. 目标与范围

本轮升级回应以下试玩反馈：音乐过小且缺少持续背景音乐、交互反馈偏弱、开场缺少玩法介绍、特殊机制与进攻手段不足、玩家船体偏大、难度仍可提高、三幕背景只是换色而没有真正换世界。

目标版本为 `2.2.0`。保留移动、冲刺、收集、强化、Boss 与移动端操作，新增一套主动技能、四套独立世界、三种环境规则、动态音乐分层及更高压但仍可读的敌人组合。单局时长继续保持 100 秒主线加 26 秒 Boss，不通过缩短反应时间制造难度。

## 2. 设计支柱

1. **每次换幕都像进入新游戏世界**：几何、色彩、背景运动、HUD 材质、环境规则和音乐全部切换，不再只对同一背景换色。
2. **多一种主动进攻，而不是自动清屏**：新技能由收集光核积蓄，满能量后发射一束中短距离窄激光，要求玩家主动瞄准并选择穿透路线。
3. **音乐持续存在并随压力生长**：从氛围层逐步叠加低音、节奏与旋律，强反馈音效短暂压低音乐但不让背景音乐消失。
4. **难度来自组合与空间规则**：提高密度、编队频率和敌人协同，但所有高伤行为继续保留方向、形状、颜色和时间预警。

## 3. 四套独立世界

### 第一幕 · 幽光深渊 / 0–30 秒

- **画风**：深蓝与青绿生物荧光，远景海沟剪影、中景水母灯群、近景气泡和柔性水流线。
- **运动语言**：曲线缓慢漂移，水母上下浮动，景深层之间存在明显速度差。
- **环境机制：潮流带**：每 7–10 秒出现一条宽而透明的流向带，提前 0.8 秒显示箭头，对玩家、敌人和光核施加轻微横向推力；不会直接造成伤害。
- **敌人学习**：Hunter 与 Swarm 为主，不提前泄漏 Striker、Lancer、Mine 或 Bulwark。
- **HUD**：圆角声呐框、青色刻度、低密度扫描波纹。

### 第二幕 · 数据都市 / 30–64 秒

- **画风**：紫蓝全息城市，远景楼群、中景数据车流、近景透视光轨与浮动广告符号。
- **运动语言**：水平视差、直线切换、方块数据包和高速光带。
- **环境机制：移动隔离带**：每 8–11 秒有一条数据墙从边缘扫入，0.9 秒前显示完整路径；墙体不是实体碰撞，而是高压区域，停留其中会降低冲刺恢复并增强敌人追踪。
- **敌人学习**：加入 Striker 与 Lancer，pincer/crossfire 从本幕开放。
- **HUD**：直角模块、紫色数据分栏、短促故障切换；不使用影响文字可读性的随机抖动。

### 第三幕 · 赤红星炉 / 64–100 秒

- **画风**：红橙恒星风暴，远景太阳弧、中景熔融裂隙、近景旋转残骸和热浪环。
- **运动语言**：旋转、喷发、向中心卷曲；危险区域使用橙红，但光核继续保持金色实体轮廓。
- **环境机制：引力井**：每 9–12 秒生成一个有半径刻度的引力区，1 秒预告后缓慢吸引玩家、敌人和光核；冲刺可快速挣脱，引力井不直接扣血。
- **敌人学习**：加入 Mine、Bulwark、mine-wall 与 elite-escort，三类威胁可同时组合。
- **HUD**：工业警戒框、橙红热量条、粗分隔线与熔融高光。

### Boss 幕 · 虚空圣堂 / 100–126 秒

- **画风**：黑、白、冷青和少量洋红；巨大同心建筑、空间裂缝、悬浮棱柱与反向流动粒子。
- **运动语言**：对称、收缩、反向旋转；二阶段让圣堂结构裂开，但不使用全屏强闪。
- **环境规则**：不再生成普通环境事件，避免与 Boss 高密度攻击叠加；背景只承担节奏与相位表达。
- **HUD**：黑白仪式框架、Boss 稳定度成为中心视觉层级。

## 4. 世界切换架构

- 新增 `src/game/realms.js`：保存每幕名称、CSS 主题、颜色、音乐参数、环境事件参数和敌人开放表。
- 新增 `src/game/realm-backgrounds.js`：创建、更新、切换和释放四套 Three.js 背景组。
- 四套背景在开局时一次创建，使用共享几何、Points/LineSegments 和有限数量材质；非当前背景隐藏且停止逐帧更新。
- 换幕时当前背景与下一背景交叉淡化并做轻微位移，目标时长 0.9 秒；`prefers-reduced-motion` 下立即切换。
- `document.documentElement.dataset.realm` 同步驱动 HUD、遮罩、扫描线、按钮和任务面板样式。
- 移动/粗指针档位减少背景粒子与装饰数量，但保留轮廓、环境机制提示和主要视差层。

## 5. 动态音乐与混音

### 音频总线

Web Audio 图调整为：

`Master ← Music + SFX + Ambience + UI`

- Master 默认目标约 `-3 dB`，加入 DynamicsCompressor 作为安全限幅，避免多层声音叠加削波。
- Music、SFX、Ambience、UI 使用独立 GainNode；静音只控制 Master，不销毁上下文。
- 强冲刺、光矛发射、受伤与 Boss 命中触发约 `-5 dB` 的音乐 duck，攻击 20–35ms、释放 260–420ms。

### 持续音乐

- 不依赖外部版权音乐文件，使用 Web Audio 振荡器、噪声缓冲与节拍调度构成可循环的原创生成音乐。
- 每幕定义独立 BPM、根音、音阶和节奏模板：幽光深渊 92 BPM、数据都市 116 BPM、赤红星炉 132 BPM、虚空圣堂 140 BPM。
- 音乐包含四层：Pad/Ambience、Bass、Pulse/Drums、Arp/Lead。
- 开局立即播放 Pad 与低音；敌人密度、Boss 阶段和光矛满能状态决定节奏层与旋律层增益。
- 换幕在下一个小节边界交叉切换音阶与节奏，最大等待不超过一小节；失败、胜利和升级使用独立短乐句。

### 音效强化

- 将当前过小的事件音量提高，并按总线留出余量；重复音效加入约 ±4% 音高和轻微音量变化。
- 增加光矛充能、能量满载、蓄力、发射、穿透命中、环境事件启动与阶段跃迁音效。
- 近失、击破、拾取、冲刺和受伤拥有不同低频/高频重点，确保不只靠画面识别事件。
- 音频上下文无法创建或处于 suspended 时，游戏继续运行；第一次用户输入继续负责 unlock/resume。

## 6. 新主动技能 · 潮汐光矛

### 输入与界面

- 键盘使用 `E`，触屏新增独立光矛按钮；技能不占用现有冲刺按钮。
- HUD 将现有容易误解的“护盾充能 / OVERDRIVE”区域改为“光矛充能”，显示 `0–100%` 能量、激光图标和 READY 状态。
- 技能输入具有 0.14 秒缓冲，暂停、升级选择、失败或胜利状态不接受技能输入。
- 能量不足时按钮保持禁用；键盘误触只让能量条短促提示，不播放发射音。

### 能量积攒

- 光矛使用独立 `0–100` 能量条，没有按时间自动恢复的冷却。
- 每拾取一个光核增加 5 点能量，至少需要拾取 20 个光核才能完成一次充能；险闪、击破和时间经过都不增加光矛能量。
- 能量达到 100 后停止溢出，继续拾取仍正常计分；只有玩家主动按下 `E` / 技能按钮才会消耗全部 100 点能量。
- 原有自动触发的 OVERDRIVE 机制移除，避免“护盾、能量、强化状态”三套概念互相混淆。
- 原 `Overclock` 强化改为“光矛聚焦”：每个光核提供的光矛能量从 5 提高到 7，但不会降低满能量发射门槛。

### 发射与命中规则

- 按下技能后先进行 0.28 秒蓄力，锁定玩家当时朝向；蓄力期间移动速度降低 20%，但没有无敌帧。
- 激光激活 0.32 秒，长度 7.2 世界单位、全宽 0.55；不会贯穿整个屏幕，也不会形成圆形范围清屏。
- 激光使用白色核心与当前世界主色外辉光，蓄力线从细到粗，视觉全宽必须与碰撞宽度一致。
- 一次光矛最多穿透 5 个普通目标；同一实体最多结算一次。命中第五个目标后，后续目标只显示擦过反馈，不受伤害。
- Swarm、Hunter、Striker 受到 1 点伤害；Mine 与 Lancer 受到 2 点伤害；Bulwark 受到 1 点伤害；Boss 受到 3 点稳定度伤害。
- 光矛可打断普通敌人的 telegraph，但不能取消已经执行的光束、冲击波、环境事件或 Boss 攻击。
- 发射结束后能量归零，必须重新收集光核；不存在第二圈、自动连发或双重激光。

### 船体、冲刺与“护盾”说明

- 游戏不再使用独立护盾机制，也不显示“护盾充能”。
- 三个船体格就是玩家生命；受到伤害会失去船体，船体归零则失败。
- 冲刺期间的短暂无敌改称“相位状态”，只是冲刺动作的一部分，不需要积攒护盾能量。
- 玩家模型外侧的防护光形只在冲刺相位或受击无敌时间出现，不代表额外可消耗护盾。

## 7. 玩家船体与交互感

- 玩家视觉基础缩放调整为当前的约 88%，碰撞半径从 `0.42` 调整为 `0.37`。
- 尾焰、核心和翼面仍保持可辨识，缩小不降低命中反馈尺寸；相位外壳与激光起点使用碰撞半径而非视觉尺寸计算。
- 移动启动增加短促推进音与尾焰增亮；急转弯产生轻微侧向尾迹；冲刺结束增加压缩回弹。
- 收集光核增加吸附轨迹与逐步升高的充能音阶；光矛连续穿透时显示 `PIERCE ×N`，打断敌人时显示 `INTERRUPT`。

## 8. 难度与攻击多样性

- 敌人硬上限提升为桌面 42、粗指针设备 32；粒子和拖尾仍使用硬上限，移动端背景预算同步压缩。
- 普通生成间隔目标调整为 `0.62 / 0.46 / 0.34` 秒，绝对下限 `0.26` 秒。
- 组合事件周期从 5–9 秒调整为 4–7 秒，并继续遵守 `minStage`、安全缝、威胁成本与设备上限。
- 第二幕增加 Lancer 三连慢速能量弹与 Striker 扇形交叉预警。
- 第三幕 Mine 可形成有延迟的连锁引爆；Bulwark 被命中后可触发一次 0.55 秒预警的装甲反击。
- Boss 二阶段增加一轮可冲刺穿越的虚空棱片，但不与横扫光束在同一预警窗口叠加。
- 生命值低时继续保留动态喘息预算；难度提升不取消 telegraph，也不让环境事件直接造成瞬时伤害。

## 9. 游戏介绍与教学

- 开场 Overlay 增加简短世界观、胜利条件、四段旅程时间轴、移动/冲刺/潮汐光矛/船体生命四个机制卡片，以及主要危险颜色说明。
- 保持单个“进入潮汐”按钮，不额外增加强制教程步骤。
- 每幕首次进入时，Banner 同时显示世界名称和环境规则一句话。
- 首次光矛 READY 时提示 `E / 技能按钮：锁定朝向，发射窄束光矛`；重复开局只保留简短提示。
- 所有介绍内容支持键盘焦点、触屏点击、ARIA 标签和窄屏纵向布局。

## 10. 状态与数据流

- `state` 新增 `weaponEnergy`、`laserState`、`laserTimer`、`laserDirection`、`laserSequence`、`realmTransition`、`environmentEvent` 与对应统计。
- 纯规则放入 `src/game/skill.js`：拾取充能、满能判定、激光阶段、长度/宽度、穿透上限、线段命中与单目标单次结算。
- `realms.js` 只保存数据，不依赖 DOM 或 Three.js；背景模块读取 realm 数据并管理渲染资源。
- 音频系统只接收 `stageIndex`、`intensity`、`laserReady`、`bossPhase` 与事件名，不读取游戏实体数组。
- 重开、失败、胜利和 Boss 接入必须清除激光、环境事件、投射物、背景过渡与音频调度状态。

## 11. 性能与无障碍

- 背景、激光 Mesh、投射物和环境提示全部使用池或固定对象；逐帧更新不创建材质、几何或大量临时向量。
- 桌面继续使用 Bloom；移动、窄屏、粗指针和减少动态模式使用轻量路径。
- reduced-motion 禁止快速背景扫动、强震屏和连续闪烁；环境规则改为离散位置/颜色阶段，但计时与碰撞不改变。
- 所有高伤敌人攻击、环境影响和光矛 READY 提示都同时使用形状、方向、颜色与文字/声音至少两种通道。
- 音频不可用、浏览器拒绝自动播放或设备性能较低时，核心战斗与通关逻辑保持完整。

## 12. 测试与验收

### 单元测试

- 四个 realm 的名称、阶段、音乐参数、CSS 主题和环境机制必须互不相同。
- 光核充能、满能发射、能量消耗、激光阶段、窄束线段碰撞、五目标穿透上限与单目标单次命中均有纯函数测试。
- 敌人上限、生成间隔、编队周期与 `minStage` 继续受测试锁定。
- 音频调度测试覆盖持续节拍、阶段换曲、静音/恢复不追赶旧节拍、duck 恢复和事件音量上限。

### 浏览器矩阵

- 开场介绍在桌面、390×844 手机和 1024×768 粗指针设备无溢出，键盘焦点顺序正确。
- `E` 与触屏按钮均只能在 100 能量时释放光矛；能量显示、朝向锁定、范围限制、穿透、打断、Boss 伤害和重开清理正确。
- 依次进入四个阶段时，背景组、CSS realm、音乐参数和环境规则全部切换，且非活动背景停止更新。
- 桌面/粗指针敌人、粒子、拖尾、投射物和背景对象不超过预算。
- reduced-motion、暂停/恢复、低帧率、胜利、超时与重开均不遗留激光、环境、音频或渲染资源。

### 发布门槛

- `npm test`、生产构建、语法检查和 Chrome 浏览器矩阵全部通过。
- 实机截图至少覆盖幽光深渊、数据都市、赤红星炉与虚空圣堂，并能不依赖文字区分四种画风。
- 实际试听确认背景音乐持续可闻、强音效清晰、无明显削波，静音与恢复行为正确。
- 生成 `Neon-Tide-v2.2.0.zip` 与 SHA-256 校验文件，发布说明记录已知 bundle 提示。

## 13. 明确不做

- 不加入联网、排行榜服务器、付费系统或账号体系。
- 不增加第二套复杂武器树；本轮只新增一个高完成度主动技能。
- 不使用有版权风险的外部音乐或未授权素材。
- 不让环境事件直接造成无预警伤害，不用纯随机全屏闪烁制造难度。
