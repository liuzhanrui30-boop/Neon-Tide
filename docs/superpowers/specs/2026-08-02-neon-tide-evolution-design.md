# Neon Tide 2.0 · 潮汐进化设计规格

## 1. 目标

把《Neon Tide · 霓虹潮汐》从“完成度较高的 45 秒躲避收集原型”进化为一款低门槛、强手感、可重复游玩的短局动作 Roguelite。玩家仍然只需要移动和冲刺，但每 10–20 秒都要遇到新的压力、选择和视觉高潮。

目标体验关键词：**顺滑、险中求胜、冲刺反杀、阶段升级、首领决战、霓虹海啸**。

## 2. 现状审计

### 已有优势

- 菜单、HUD、霓虹配色和版式已经形成清晰品牌感。
- 正交相机、XY 平面玩法和触屏摇杆适合浏览器快速开局。
- 冲刺、无敌、粒子、闪屏、震动和合成音效已具备基础反馈链。
- 运行包很轻，适合静态站点和移动浏览器。

### 玩家侧问题

- 核心循环只有“捡光核 → 躲追兵”，约 15 秒后开始重复。
- 能量条只增长、不形成能力或决策，玩家无法理解其价值。
- 敌人只有追踪型，危险没有节奏、预判和反制差异。
- 冲刺主要是逃跑工具，缺少主动击破和高风险高收益。
- 45 秒结束没有关卡转折或首领高潮，胜利更像倒计时结束。
- 连击只增加分数，缺少近失、反杀、阶段奖励等高手表达。
- 屏幕震动采用逐帧随机偏移，容易产生噪点感而不是有重量的冲击。
- 单文件同时负责输入、状态、生成、渲染、音频和 UI，继续加内容会提高回归风险。

## 3. 方向比较

### 方向 A：纯打磨原版

保持 45 秒、单敌人和收集目标，只优化移动、粒子和 UI。风险最低，但无法解决中后段重复和“缺少闯关感”。

### 方向 B：短局三幕式动作 Roguelite（采用）

扩展为约 65 秒的三阶段航行，加入敌人种类、阶段模块选择、自动超载、冲刺反杀和最终首领。保留两种基础操作，内容增长由数据驱动，不把游戏做成复杂射击游戏。

### 方向 C：完整章节战役

制作多张地图、剧情、永久成长和关卡选择。长期潜力最高，但会稀释当前“打开即玩”的优势，也超出本轮高质量垂直切片范围。

## 4. 产品支柱

1. **两秒上手**：移动＋冲刺，不增加必须记忆的新战斗按键。
2. **冲入危险，而非只逃离危险**：冲刺能击破普通敌人、削弱精英和首领，并返还能量。
3. **每幕都有新问题**：追踪、预警突袭、封锁区域和首领冲击分别考验走位。
4. **表现服务读秒**：颜色、形状、音色和预警动画必须帮助玩家识别危险，而不是只增加装饰。
5. **短局可复玩**：模块选择、动态导演、连击和评级让每局路线不同。

## 5. 核心循环

### 秒级循环（1–6 秒）

观察威胁与光核 → 加速切线移动 → 贴近危险制造近失 → 冲刺穿越敌人或逃离包围 → 获得分数、能量、连击和短促反馈 → 立即寻找下一条高收益路线。

### 阶段循环（18–22 秒）

学习当前敌人组合 → 提高连击与超载效率 → 撑过浪潮峰值 → 进入潮门并选择一个模块 → 带着强化进入下一阶段。

### 单局循环（约 65 秒）

静潮航道 → 裂流航道 → 风暴眼 → 潮汐守卫首领 → 结算评级 → 立即重开并尝试更高连击或不同模块。

## 6. 操作与手感

- 移动采用加速、转向、松手阻尼三组独立参数；快速但不漂，触屏与键盘共用同一运动模型。
- 飞船朝速度方向平滑转向，并根据横向转弯产生轻微倾斜和尾焰拉伸。
- 相机产生小幅速度前视，让玩家看见即将进入的空间。
- 冲刺拥有 2 格相位充能，单格独立恢复；允许在冷却将结束前短暂缓冲输入。
- 冲刺期间碰撞普通敌人会将其击破；精英和首领需要多次冲击。
- 冲刺击破会返还部分充能、延长连击并产生短暂慢动作，形成“击破 → 再冲刺”的节奏。
- 光核在近距离被磁吸，超载期间吸附半径和移动速度显著提升。
- 敌人从碰撞圈外擦过会触发“险闪”，奖励分数、能量和 0.1 秒视觉慢镜；同一敌人只能奖励一次。

## 7. 关卡与动态导演

### 第一幕：静潮 / 0–18 秒

- 敌人：追踪者。
- 教学：收集、冲刺击破、险闪。
- 压力曲线：低密度，确保玩家先获得一次成功反杀。

### 第二幕：裂流 / 18–38 秒

- 新敌人：突袭者。先显示攻击轨迹，再沿直线高速穿越战场。
- 生成交替使用边缘追踪、双侧夹击和突袭线，迫使玩家读预警而不是绕圈。
- 18 秒进入模块选择。

### 第三幕：风暴眼 / 38–53 秒

- 新敌人：潮雷。固定后蓄力，爆发扩张危险环，可被冲刺提前击破。
- 追踪者、突袭者和潮雷组合生成，加入精英追踪者。
- 38 秒进入第二次模块选择。

### 首领幕：潮汐守卫 / 53 秒后

- 巨型多环首领进入场地，拥有 6 点稳定值。
- 行为轮换：锁定冲撞、径向脉冲、召唤追踪者。
- 玩家必须用冲刺命中核心；普通接触仍会受伤。
- 首领被击破立即胜利；进入首领幕 18 秒仍未击破则信号崩解并失败。

### 动态难度边界

- 随阶段提高生成预算，但同时限制屏幕总敌人数和同类危险数量。
- 玩家仅剩 1 点生命时降低一次组合生成强度，并提高修复光核概率。
- 高分玩家只增加组合复杂度，不直接提升所有敌人速度，避免不可读。

## 8. 能量、超载和模块

### 能量

- 收集光核、险闪和冲刺击破均提供能量。
- 达到 100 自动进入 5 秒“潮汐超载”，避免增加新按键和移动端按钮。
- 超载效果：移动速度 +18%、光核磁吸增强、冲刺恢复加快、碰撞轮廓强化、分数倍率提升。

### 阶段模块

每个潮门从 5 个模块中给出 3 个不重复选项：

- 相位电容：冲刺恢复速度 +25%。
- 引力阵列：磁吸半径 +45%。
- 超频推进：移动速度 +12%。
- 共振核心：所有能量获取 +25%。
- 纳米修复：立即恢复 1 点船体，并提高最大船体到 4。

选择界面暂停模拟，支持鼠标、触屏以及数字键 1/2/3。

## 9. 敌人视觉语言

- **追踪者**：红色尖头三角，持续朝向玩家，危险来自跟随。
- **突袭者**：洋红细长箭头，蓄力时显示直线预测轨迹，危险来自时机。
- **潮雷**：橙色六边核心与扩张圆环，危险来自区域封锁。
- **精英**：白红双层轮廓、明显护盾环和更大尺寸，不能被一次冲刺击破。
- **首领**：多重旋转环、中心裂隙核心、全宽首领稳定条，所有攻击均有至少 0.55 秒预警。

## 10. 美术与界面升级

- 背景随阶段从深青蓝、紫红、橙红过渡到首领幕的白青高对比。
- 增加两层流场弧线、漂移光尘和战场边界脉冲，形成“潮汐正在移动”的感觉。
- 飞船增加侧翼、中心动力核和更清晰的冲刺拖尾。
- HUD 新增阶段名、阶段进度、两格冲刺充能、超载状态和首领稳定条。
- 关卡切换使用大字阶段横幅、短促缩放、色偏线和声音上扬。
- 分数结算显示评级 S/A/B/C、最高连击、险闪次数和击破数。
- 移动端保留左摇杆和右冲刺；按钮用双环显示两格充能，关键信息避开拇指区。
- `prefers-reduced-motion` 下关闭慢镜、缩放脉冲和大幅震动，保留颜色与文本反馈。

## 11. 音频方向

- 使用 Web Audio 合成分层节拍，不引入音频文件和额外下载。
- 每阶段改变节拍密度、低频音高和高频脉冲，首领幕提高节奏紧迫度。
- 收集、险闪、击破、受伤、模块选择和首领受击使用不同音域，避免反馈混淆。
- 页面失焦、暂停或静音时停止节拍调度，恢复后从当前阶段重新接入。

## 12. 技术架构

### 文件边界

- `src/game/config.js`：所有平衡参数、阶段、敌人和模块数据；不访问 DOM 或 Three.js 场景。
- `src/game/gameplay.js`：阶段判断、奖励、评级和生成预算等纯函数；可用 Node 内置测试独立验证。
- `src/game/audio.js`：唯一拥有 `AudioContext` 的音频系统，对外只暴露语义事件。
- `src/main.js`：唯一拥有运行时状态和场景实体数组，按固定顺序驱动输入、导演、实体、碰撞、反馈和 UI。
- `src/style.css` 与 `index.html`：只负责表现和可访问交互，不写玩法状态。

### 状态所有权

- `state.mode` 是菜单、进行、模块选择、暂停、胜负的唯一模式源。
- 生命、能量、分数、阶段、升级和统计只由主运行时写入。
- 实体表现对象不直接修改全局状态，碰撞结果通过语义函数处理。
- 慢动作只影响模拟 `scaledDt`，HUD 计时和反馈衰减使用真实 `dt`。

### 每帧顺序

输入采样 → 阶段/导演 → 玩家移动 → 敌人行为 → 收集物 → 碰撞解析 → 粒子与拖尾 → 相机与屏幕反馈 → HUD → 渲染。

## 13. 性能与可访问性约束

- 保持 Three.js `0.180.x` 和 Vite `7.x`，不增加运行时依赖。
- DPR 上限保持 2；移动端低宽度设备自动降低背景粒子数量。
- 敌人材质和几何体复用；高频粒子、拖尾和浮字使用池或严格数量上限。
- 同屏敌人上限 24、活动粒子上限 220、拖尾节点上限 36。
- 所有危险必须同时用形状、颜色和动画提示，不能只靠颜色区分。
- 浏览器失焦自动暂停；触屏、键盘和鼠标都能完成完整流程。

## 14. 验收标准

- 新玩家只用移动和冲刺即可在第一幕理解收集、击破与险闪。
- 一局至少出现三种普通敌人、两次模块选择和一次首领战。
- 能量达到 100 后存在清晰、可感知且有实际收益的超载状态。
- 冲刺击破、险闪、受伤、阶段切换和首领击破拥有强弱分层反馈。
- 菜单、进行、模块选择、暂停、失败、胜利均可稳定往返，不发生重复结算。
- 桌面和移动布局无关键 UI 遮挡，上传到子路径后无资源 404。
- 纯逻辑测试、生产构建、静态服务器资源检查和无头浏览器控制台检查全部通过。

## 15. 自检结论

规格不存在待定项；核心循环、关卡时序、敌人反制、状态所有权、移动端和验收方式相互一致。本轮范围聚焦单局垂直切片，不加入账号、联网、商城、剧情章节或永久数值成长。
