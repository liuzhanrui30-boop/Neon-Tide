# Neon Tide 游戏设计文档（v2.2 稳定线）

## 玩家承诺

玩家驾驶一艘小型信号艇，在四个完全不同的霓虹领域中生存 100 秒，收集光核积攒潮汐光矛，阅读预警、选择路线并躲过越来越密集的敌方编队，最后在 26 秒 Boss 窗口内主动击破深潮主脑。

## 设计支柱

1. **躲避优先**：不要求手动瞄准；移动位置、相位冲刺和路径选择是核心技能。
2. **危险可读**：所有高伤害攻击先预警，再进入生效阶段；颜色、形状和节奏共同表达危险。
3. **主动胜利**：Boss 不能靠苟活通关；必须用冲刺和满能量潮汐光矛造成真实伤害。
4. **领域差异**：深渊暗流、数据车道、星铸重力和虚空圣堂分别改变移动决策、节奏和视觉。
5. **可重复成长**：两个强化节点提供构筑变化，失败后可从检查点重新挑战。

## 核心循环

```text
移动躲避 → 收集光核 → 光矛充能 → 读预警/冲刺反击
→ 阶段升级 → 领域切换 → Boss窗口 → 击破或失败结算
```

## 规则合同

### 玩家

- 基础船体 3 格；受到伤害后进入短暂无敌。
- 移动使用 WASD/方向键；Space 相位冲刺；E 潮汐光矛。
- 冲刺具有独立充能和恢复时间，冲刺期间无敌并可击破部分敌人。
- 不存在手动瞄准系统；自动武器按合法目标规则选择附近敌人/Boss弱点。

### 资源

- 光核是主要拾取物，增加分数并积攒光矛能量。
- 光矛必须达到满能量后才能发射；每次发射有窄束范围和目标上限。
- 强化在阶段节点暂停游戏，玩家从 3 个未拥有选项中选择 1 个。

### 阶段

| 时间 | 阶段 | 主要压力 |
| --- | --- | --- |
| 0–30s | Neon Drift | Hunter、Swarm、基础编队 |
| 30–64s | Signal Surge | Striker、Lancer、数据车道 |
| 64–100s | Crosscurrent | Mine、Bulwark、重力/交叉突袭 |
| 100–126s | Event Horizon | Boss 窗口、终境环境 |

### 四领域

| 领域 | 玩法关键词 | 视觉/声音 |
| --- | --- | --- |
| 深渊潮界 | 暗流、焦散、追猎 | 深蓝、青色、低沉脉冲 |
| 数据都市 | 车道、路线迁移、封包 | 紫色、粉色、切分节拍 |
| 星铸熔炉 | 重力、熔核、陨石压力 | 橙红、金色、快速鼓点 |
| 虚空圣堂 | 逆流、镜像、终局 | 冰白、青蓝、空旷和声 |

## 敌人角色

- Hunter/Chaser：基础追踪，教玩家保持移动。
- Striker：高速切入，提前给出方向预警。
- Lancer：远程线性攻击，要求横向换位。
- Swarm：数量压力，迫使玩家提前离开局部区域。
- Mine：固定威胁，拥有明显膨胀预警。
- Bulwark/Elite：高生命值与路线占位，适合冲刺或光矛处理。
- Boss：分阶段攻击、真实弱点和独立结算窗口。

## 胜负与结算

- 失败：船体归零或 Boss 窗口结束而 Boss 未被击破。
- 胜利：Boss 生命归零，清理 Boss 敌人、投射物、预警、音乐层和 HUD 状态。
- 结算记录：分数、最高分、连击、险闪、击破数、评级。

## UX 与无障碍

- 键盘、触屏和暂停按钮拥有一致语义。
- 支持 reduced motion、危险高对比、HUD 精简和音量设置。
- 危险不可只依赖颜色；预警形状、方向、文字和节拍要同时保留。

## 验收标准

- `npm test` 全部通过。
- 生产构建资源从 GitHub Pages 子路径零 404。
- 新增敌人/领域/升级必须有纯逻辑测试。
- 桌面键盘和移动触屏均可开始、暂停、强化、失败和胜利。
- 光矛不能在未满能量时发射；Boss 不能只靠生存计时获胜。
