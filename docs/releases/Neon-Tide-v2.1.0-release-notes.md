# Neon Tide · 霓虹潮汐 v2.1.0 发布说明

发布日期：2026-08-03

## 本次升级

- 主线延长为三幕 100 秒，Boss 战 26 秒，总局约 126 秒。
- 敌人密度提高至桌面 36、粗指针设备 28 的硬上限，并加入夹击、交叉火力、雷墙、螺旋和精英护航编队。
- Hunter、Striker、Lancer、Swarm、Mine、Elite 形成不同移动与攻击语言；所有高伤行为保留明确预警。
- Boss 新增第一阶段组合攻击与生命低于 50% 后的第二阶段：横扫光束、三角脉冲、侧翼蜂群。
- 玩家船体、敌人轮廓、核心、尾焰、背景流体、雾光、命中反馈和 HUD 全面精修。
- 桌面使用受控 Bloom 与 OutputPass；移动、窄屏、粗指针和减少动态偏好使用轻量路径。
- 增加对象池硬上限、热循环向量复用、NaN/Infinity 修复、孤儿实体退役、Composer 生命周期和重开清理防护。

## 操作兼容

- 键盘：WASD/方向键移动，空格冲刺，P/Esc 暂停。
- 触屏：虚拟摇杆、冲刺按钮、暂停按钮。
- 支持键盘焦点、ARIA 状态提示和 `prefers-reduced-motion`。
