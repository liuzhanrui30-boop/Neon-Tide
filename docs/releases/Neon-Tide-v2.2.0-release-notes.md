# Neon Tide · 霓虹潮汐 v2.2.0 发布说明

发布日期：2026-08-06

## 四境航线

- 主线由深渊潮界、数据都市、星铸熔炉和虚空圣堂组成，时间边界为 `0/30/64/100/126` 秒。
- 四境分别使用独立背景几何、CSS 主题、92/116/132/140 BPM 音乐和环境规则。
- 暗流会推动场内单位，数据车道会降低冲刺充能恢复，引力井会拉动场内单位；终幕首领战禁用普通领域事件。

## 战斗与音频

- 新增由光核充能的潮汐光矛：普通光核 +5 能量，Overclock 后 +7，满 100 后可用键盘 `E` 或触屏光矛按钮发射。
- 能量只在成功开始发射时清零；冲刺中、能量不足或状态冲突时不会消耗。
- 提高导演压力至桌面/粗指针敌人硬上限 42/32，加入投射物池、扩展攻击变体和更严格的清理边界。
- 自适应 Web Audio 使用 Music/SFX/Ambience/UI 四总线；暂停会停止音乐调度，并在继续后安全重相位，不改变投射物、环境或光矛的游戏时间。静音和时钟失步也会安全停止旧音乐并重新对齐节拍。
- 自然领域切换现在排队到旧领域下一小节边界，使用短淡出/淡入衔接新领域，并且每次非初始自然进入只触发一次 `realmShift` 提示；暂停、静音、恢复和时钟失步不会制造抢拍或重复声部。
- 暂停会原位冻结敌人、投射物、领域事件、光矛状态与能量，继续后从同一状态恢复；只有终局和重开执行资源清理。

## 可访问性与输入

- 开场简报提供四机制卡、四境时间轴、胜利条件与危险说明，并限制键盘焦点在当前对话框内。
- 光矛按钮使用 `aria-disabled`；光矛充能、船体、阶段与首领稳定度使用进度条语义；领域与状态提示使用礼貌播报区域。
- 开场、暂停和强化选择结束后，键盘焦点返回游戏画布。
- 冲刺与光矛触屏按钮使用原生 `click` 激活，因此 Enter、Space、指针、触摸和辅助技术合成点击都遵循单次请求语义；不可用光矛状态不会激活。
- Boss 稳定度的 `aria-valuetext` 直接报告精确当前值/最大值，不再假设固定伤害来源。
- `prefers-reduced-motion` 移除领域转场、强脉冲、镜头震动、慢动作和缩放冲击，同时保留静态预警与进度信息。

## 最终审查修复

- 自然生成的 `elite` 现在通过统一 Bulwark 角色判定进入装甲反制，仍保留执行中禁止与同一攻击令牌只触发一次的规则。
- Chaser 每段与每个实例、Striker 每个实例拥有可复用且可释放的独立预警材质；普通与减少动态模式不会互相覆盖，也不会逐帧分配材质。
- 正常帧仅保留常数级标量防护和局部实体防护；集合/全领域结构审计改为脏触发、生命周期触发、显式恢复或低频执行。
- 投射物池使用按索引保存的唯一材质与网格所有权，可本地修复空项、错误类型、材质别名、外来材质数组和子级资源，同时保护共享几何并保持场景子项、池长度及容量稳定。
