# Neon Tide · 霓虹潮汐 v2.2.0 发布说明

发布日期：2026-08-06

## 四境航线

- 主线由深渊潮界、数据都市、星铸熔炉和虚空圣堂组成，时间边界为 `0/30/64/100/126` 秒。
- 四境分别使用独立背景几何、CSS 主题、92/116/132/140 BPM 音乐和环境规则。
- 暗流会推动场内单位，数据车道会降低冲刺充能恢复，引力井会拉动场内单位；终幕首领战禁用普通领域事件。

## 战斗与音频

- 新增由光核充能的潮汐光矛：普通光核 +5 能量，Overclock 后 +7，满 100 后可用键盘 `E` 或触屏光矛按钮发射。
- 能量只在成功开始发射时清零；冲刺中、能量不足或状态冲突时不会消耗。
- 提高导演压力至桌面/粗指针敌人硬上限 42/32，加入投射物池、扩展攻击变体和更严格的清理边界。
- 自适应 Web Audio 使用 Music/SFX/Ambience/UI 四总线；暂停会停止音乐调度，并在继续后安全重相位，不改变投射物、环境或光矛的游戏时间。静音、领域切换和时钟失步也会停止旧音乐并重新对齐节拍。
- 暂停会原位冻结敌人、投射物、领域事件、光矛状态与能量，继续后从同一状态恢复；只有终局和重开执行资源清理。

## 可访问性与输入

- 开场简报提供四机制卡、四境时间轴、胜利条件与危险说明，并限制键盘焦点在当前对话框内。
- 光矛按钮使用 `aria-disabled`；光矛充能、船体、阶段与首领稳定度使用进度条语义；领域与状态提示使用礼貌播报区域。
- 开场、暂停和强化选择结束后，键盘焦点返回游戏画布。
- `prefers-reduced-motion` 移除领域转场、强脉冲、镜头震动、慢动作和缩放冲击，同时保留静态预警与进度信息。

## 验证

- 单元测试：53/53 通过。
- Chrome 146 浏览器矩阵：19/19 通过，覆盖桌面、390×844 手机、1024×768 平板、焦点/ARIA、键盘与触屏光矛、四境数据与背景、暂停冻结/恢复、终局清理和非有限数值注入恢复。
- 生产构建、JavaScript 语法检查、解压比对、桌面与 390 宽 artifact smoke 均属于发布门禁。
