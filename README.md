# Neon Tide · 霓虹潮汐 2.0

使用 Three.js 制作的单页霓虹街机生存游戏。驾驶信号艇穿过三段不断增强的数字潮汐，途中选择强化，最终击破终幕首领「深潮主脑」。

## 最终目标

1. 收集黄色光核、躲避或冲刺击破追猎信号，坚持到第 53 秒。
2. 在两个阶段节点选择强化。
3. 深潮主脑出现后，在 18 秒内用冲刺命中并清空其稳定度；仅坚持到倒计时结束不会获胜。

结算会显示本局碎片、最高记录、最高连击、险闪次数、击破数与评级（S/A/B/C）。最高记录保存在浏览器本地。

## 操作

| 操作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 移动 | `WASD` / 方向键 | 左下角虚拟摇杆 |
| 脉冲冲刺 | `Space` | 右下角冲刺按钮 |
| 暂停 / 继续 | `P` / `Esc` 或右上角按钮 | 右上角按钮 |
| 选择强化 | 数字键 `1`–`3` 或点击 | 点击强化卡片 |
| 静音 | 右上角音符按钮 | 右上角音符按钮 |

冲刺期间短暂无敌，并可击破普通敌人或削减首领稳定度。连续收集、险闪和击破会提高连击与得分；能量充满后进入短暂 OVERDRIVE。

## 本地运行

需要 Node.js 22 或兼容版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可游玩。

## 测试与生产构建

```bash
npm test
npm run build
```

生产文件输出到 `dist/`。Vite 使用相对资源路径，因此可以部署在域名根目录、子路径或 HTML5 游戏托管平台。发布 ZIP 应直接压缩 `dist/` 内的内容，确保 `index.html` 位于压缩包根目录。

## 技术与可访问性

- Three.js `OrthographicCamera` 与 XY 平面几何体构成 2D 场景。
- 菜单、进行中、强化、暂停、失败和胜利状态彼此独立。
- 包含对象池粒子、冲刺拖尾、分层反馈、屏幕震动与 Web Audio 动态音效。
- 自适应桌面和移动视口，设备像素比最高为 2。
- 支持键盘焦点、对话框语义、触屏输入及 `prefers-reduced-motion` 减少动态效果。
