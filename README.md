# Neon Tide · 霓虹潮汐 2.2

使用 Three.js 制作的单页霓虹街机生存游戏。驾驶信号艇穿越四个视觉、音乐与环境规则完全不同的领域，在高密度编队中读预警、选路线、以相位冲刺反击，并在终幕窗口摧毁「深潮主脑」。

## 最终目标

1. 收集黄色光核，为潮汐光矛充能，并在追猎、交叉突袭、远程光束、蜂群、雷墙和领域事件之间坚持到第 100 秒。
2. 在 30 秒和 64 秒节点各选择一次强化。
3. 深潮主脑出现后，在 26 秒内用冲刺与光矛削减稳定度；仅坚持到倒计时结束不会获胜。

三格船体就是玩家的全部生命，船体归零即失败。冲刺期间进入短暂相位状态并获得无敌时间；相位只属于冲刺动作，不是额外生命资源。

## 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | `WASD` / 方向键 | 左下角虚拟摇杆 |
| 相位冲刺 | `Space` | 右下角冲刺按钮 |
| 潮汐光矛 | `E` | 右侧光矛按钮 |
| 暂停 / 继续 | `P` / `Esc` 或右上角按钮 | 右上角按钮 |
| 选择强化 | 数字键 `1`–`3` 或点击 | 点击强化卡片 |
| 静音 | 右上角音符按钮 | 右上角音符按钮 |

对话框会限制键盘焦点；进入战斗、继续游戏或完成强化选择后，焦点返回游戏画布。

## 潮汐光矛

- 能量范围为 `0–100`；每枚普通光核提供 5 点能量，持有 Overclock 后提供 7 点。
- 险闪、击破和首领命中只奖励分数，不提供光矛能量。
- 能量未满时键盘和触屏输入均不会发射，也不会清空已有能量。
- 满能且未处于冲刺时才能开始蓄力；只有成功开始发射才会把能量重置为 0。
- 光矛是一条窄束贯穿攻击，单次最多命中 5 个普通目标，并可独立命中首领。

## 四个领域

| 时间 | 领域 | 音乐 | 环境规则 |
| --- | --- | --- | --- |
| `0–30s` | 深渊潮界 Abyss | 92 BPM | 暗流先预警再推动玩家、敌人和光核；不直接造成伤害。 |
| `30–64s` | 数据都市 Data City | 116 BPM | 数据车道先预警；位于车道内时冲刺充能恢复速度降低 35%。 |
| `64–100s` | 星铸熔炉 Star Forge | 132 BPM | 引力井先预警再拉动玩家、敌人和光核；不直接造成伤害。 |
| `100–126s` | 虚空圣堂 Void Cathedral | 140 BPM | 首领战不再生成普通领域事件，避免与高密度首领攻击叠加。 |

每个领域拥有独立背景几何、CSS 色彩签名、环境动机和自适应音乐音阶。战斗强度提升时鼓组与琶音层逐步加入；暂停时音乐停止调度并在继续后安全重相位，同时投射物、环境计时与视觉、光矛状态和能量都原位冻结并恢复。静音、领域切换或音频时钟失步也会停止旧音轨并重新对齐节拍。

## 本地运行

需要 Node.js 22 或兼容版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可游玩。

## 测试与生产构建

```bash
npm test
npm run build
node --check src/main.js
node --check src/game/audio.js
node --check src/game/realm-backgrounds.js
node --check tests/browser-matrix.mjs
```

生产文件输出到 `dist/`。Vite 使用相对资源路径，因此可部署在域名根目录、子路径、GitHub Pages 项目站点或 HTML5 游戏托管平台。实际部署时上传 `dist/` 的全部内容，并让其中的 `index.html` 成为入口；发布 ZIP 另外保留源码、测试与文档，便于复现构建。

## 性能与可访问性

- 桌面敌人硬上限为 42，粗指针设备为 32；投射物、粒子、拖尾、后处理和领域视觉均有容量及生命周期清理。
- 桌面高质量档位使用受控 Bloom 与输出色彩处理；移动、窄屏、粗指针和减少动态模式使用轻量渲染路径。
- `prefers-reduced-motion` 会移除领域转场、强脉冲动画、镜头震动、慢动作和缩放冲击，同时保留静态预警形状与进度变化。
- 光矛按钮公开 `aria-disabled`；光矛充能、船体、阶段和首领稳定度使用进度条语义；领域与状态提示使用礼貌播报区域。
- 暂停只冻结当前敌人、投射物、领域事件与光矛，并在继续后从原状态恢复；胜利、失败、重开和页面退出才会清理终局战斗资源。以上模式都会停止不应继续的音频调度。
